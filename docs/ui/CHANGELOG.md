# Changelog

## UI engine 0.1.0 (included in glocon 0.3.0)

First release: a framework-independent UI/UX audit engine, rendered browser checks with axe, state contracts, a CLI with JSON output, React form/state primitives, shared CSS tokens, and a supplied-node native adapter.

Includes documented confidence and coverage limits, configurable severity and suppressions, ESM/CommonJS exports, TypeScript declarations, research rationale, and automated tests.
